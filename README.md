# Pizza-Analytics

### Power BI Project
This project analyzes pizza sales data to understand sales performance, customer ordering patterns, and product preferences. A comprehensive Power BI dashboard was developed to visualize sales trends across different pizza categories, sizes, and products. The dashboard helps stakeholders identify popular pizzas, monitor business performance, and make data-driven decisions to improve sales.

### Tools Covered : Advanced Excel, Power BI, Power Query

### Key Performance Indicators (KPIs):

• Total Categories

• Total Orders

• Total Sales

• Total Orders by Category

• Total Sales by Category

• Total Orders and Sales by Category

• Total Orders and Sales by Pizza

• Quantity by Category

• Total Orders by Size

• Total Sales by Size

### Dashboard Visualizations:

• Cards

• Pie Chart

• Donut Chart

• Line and Stacked Column Chart

• Table

• Stacked Column Chart

• Line Chart

### Interactive Features:

• Slicers
